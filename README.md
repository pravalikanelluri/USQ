-> University Query Bot
University Query Bot is a web application that helps students
find answers to common university-related questions.

- > Features
- Answer university-related questions
- Search academic information
- Simple chatbot interface
- Responsive design

- > Technologies Used
- React
- JavaScript
- Vite
- Tailwind CSS

- > How to run
1. Clone the repository
2. Run npm install
3. Run npm run dev

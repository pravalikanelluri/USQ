-> University Query Bot
University Query Bot is a web application that helps students
find answers to common university-related questions.

-> Architecture
User Query
    ↓
React Chat Interface
    ↓
Query Processing
    ↓
University Information
    ↓
Response
    ↓
Chatbot Interface

->Technologies
React.js,
JavaScript,
Vite,
Tailwind CSS

- > How to run
1. Clone the repository
2. Run npm install
3. Run npm run dev
